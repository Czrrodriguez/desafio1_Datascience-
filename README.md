
# 📊 Análisis de Tiendas para Venta - Proyecto Data Science

## 📅 Descripción del Proyecto

Este proyecto consiste en un análisis de datos de ventas de cuatro tiendas para ayudarle 
al Sr. Juan a decidir qué tienda de su cadena Alura Store debe vender para iniciar un nuevo emprendimiento.

Se analizaron aspectos clave del negocio como facturación, categorías más vendidas, calificaciones de clientes, productos populares y costos de envío.

Se brinda una recomendación final para el cliente.

---

## 💡 Objetivos Analizados

1. **Facturación Total por Tienda**   
2. **Ventas por Categoría**  
3. **Calificación Promedio por Tienda**  
4. **Productos Más y Menos Vendidos**  
5. **Costo Promedio de Envío por Tienda**

---

## 📈 Recomendaciones Finales

Estimado **Sr. Juan**,

A partir de los datos analizados, le recomendamos (además de lo solicitado):

- Priorizar y reforzar **Tienda 2**, dado que combina buena facturación con costos razonables.
- Aprovechar la excelente reputación de **Tienda 4** para promociones especiales.
- Continuar invirtiendo en productos de **tecnología** y **electrodomésticos**, por ser los más demandados.
- Optimizar los costos de envío en **Tienda 1** para mejorar su rentabilidad.

### 🏁 Recomendación de Venta

Como parte de su solicitud, la tienda recomendada para vender sería la **Tienda 3**, con base en los siguientes factores:

- 📉 **Menor calificación promedio**: Es la tienda peor valorada por los clientes, lo que indica problemas de satisfacción o experiencia de compra.
- 💵 **Baja facturación**: Registra el volumen de ventas más bajo en comparación con las otras tiendas.
- 🚚 **Costo de envío más alto o poco competitivo**: Esto puede estar afectando la conversión de ventas.
